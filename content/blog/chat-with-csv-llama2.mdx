# Chat CSV: ทดลองคุยกับข้อมูล CSV ด้วย Llama 2

โปรเจกต์นี้เริ่มจากไอเดียง่าย ๆ: ถ้าเราอัปโหลดไฟล์ CSV แล้วถามคำถามเกี่ยวกับข้อมูลด้วยภาษาทั่วไปได้ จะช่วยให้สำรวจข้อมูลสะดวกขึ้นแค่ไหน?

แอปสร้างด้วย Streamlit ผู้ใช้เลือกไฟล์ CSV จากหน้าเว็บ แล้วพิมพ์คำถามลงในหน้าต่างแชตได้ โดยไม่ต้องเริ่มจากการเขียนโค้ดเพื่อเปิดไฟล์และไล่ดูข้อมูลทีละส่วน

พูดตามตรง โปรเจกต์นี้เริ่มตอนที่เราอยู่ ม.5 หลังจากไปเข้าค่ายแล้วมีพี่คนหนึ่งในค่ายจ้างให้ทำ น่าจะเป็นโปรเจกต์แรกที่เราได้ตังค์ด้วย 555 แล้วโปรเจกต์นี้ก็เกิดขึ้นมา

## จากไฟล์ CSV ไปสู่คำตอบ

หลังอัปโหลดไฟล์ แอปใช้ `CSVLoader` อ่านข้อมูล จากนั้นสร้าง embeddings ด้วยโมเดล `sentence-transformers/all-MiniLM-L6-v2` ซึ่งกำหนดให้ทำงานบน CPU แล้วเก็บเวกเตอร์ที่ได้ไว้ใน FAISS

เมื่อมีคำถาม แอปใช้ `ConversationalRetrievalChain` เชื่อมตัวค้นข้อมูลกับ LLM เพื่อดึงข้อมูลที่เกี่ยวข้องมาประกอบคำตอบ พร้อมส่งประวัติการสนทนาไปด้วย เพื่อให้ถามต่อจากคำถามก่อนหน้าได้

โมเดลภาษาที่ใช้คือไฟล์ `llama-2-7b-chat.ggmlv3.q8_0.bin` ซึ่งโหลดผ่าน `CTransformers` โดยตั้งค่า `max_new_tokens` เป็น 512 และ `temperature` เป็น 0.5 ส่วนประวัติแชตระหว่างการใช้งานเก็บไว้ใน Streamlit session state

## ส่วนที่ได้ลองทำ

- รับไฟล์ CSV ผ่าน file uploader ของ Streamlit
- แปลงข้อมูลเป็น embeddings และสร้าง FAISS vector store
- เชื่อมการค้นข้อมูลเข้ากับโมเดล Llama 2 แบบแชต
- เก็บคำถามและคำตอบเพื่อรองรับการถามต่อในบทสนทนา

## สิ่งที่ยังต้องคำนึงถึง

คำตอบจาก LLM ไม่ได้รับประกันว่าจะถูกต้องเสมอไป และความเกี่ยวข้องของคำตอบขึ้นอยู่กับทั้งข้อมูลใน CSV และผลการค้นคืนจาก vector store ควรตรวจสอบคำตอบกับข้อมูลต้นทาง โดยเฉพาะเมื่อใช้ข้อมูลสำคัญ

ในโค้ดปัจจุบัน ไฟล์อัปโหลดจะถูกเขียนลงไฟล์ชั่วคราวเพื่อให้ `CSVLoader` อ่าน ส่วน vector store ถูกบันทึกไว้ที่ `vectorstore/db_faiss` ดังนั้นก่อนนำไปใช้งานจริง ควรทบทวนการจัดการไฟล์และข้อมูลที่อัปโหลดให้เหมาะกับสภาพแวดล้อมที่จะนำไปใช้

## สิ่งที่ได้เรียนรู้

สิ่งที่ได้เรียนรู้จากงานนี้คือการได้ลองทำโปรเจกต์เกี่ยวกับ LLM ในช่วงที่เทคโนโลยียังไม่บูมและยังไม่เก่งเท่าทุกวันนี้

## สิ่งที่อยากพัฒนาต่อ

ตอนทำโปรเจกต์นี้เราน่าจะอยู่ ม.5 และเป็นโปรเจกต์แรก ๆ ที่ทำ พอย้อนกลับมาดูตอนนี้ก็รู้สึกว่ายังทำได้ไม่ดีเท่าไร สิ่งที่อยากพัฒนาต่อคือปรับ UI ให้ใช้งานง่ายขึ้น และปรับโมเดลให้ตอบคำถามได้ดีขึ้น
